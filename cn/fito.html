Fito

Fito是主权社交网络，也是基维什国内互联网的基础。平台由Gorfir.Derto于1993年创建，最初旨在建立一个安全的全球互联网替代平台，保护公民免受西方影响。随着时间推移，该项目发展成全球平台，拥有先进设计、独特的人工智能内容审核系统，以及前所未有的全民“数字卫生”保障工具。

如今，Fito 不仅是基维什主要的交流工具，也是一种独特的社交网络范例：其算法被刻意设计为防止内容成瘾，引导用户“回到线下”，以维护社会的心理健康。

创立背景

1992年，Auto-Nahodki目录通过类似 DOS 的系统成功上线后，政府认识到建设独立自主互联网的必要性。在 Windows 3.1 时代，米里姆·卡拉松总统发起了安全网络开发项目。主要目标是建立一个让基维什工程人才免受外部挑衅的空间，同时使国家能够及早发现并消除危险的社会趋势。

发展历史

1993年：诞生与起步

1993年，Gorfir.Derto公司成立，并发布了 Fito 的首个版本。最初的网站只是一个简单的 HTML 外壳，类似电子邮件和 Usenet。功能仅限于通过@用户名标签查找用户、发送消息和交换照片。尽管功能简单，平台从一开始就接入了国家监管系统。

1994年：“西方梦的消沉”与对华协议取消

1994年初，Gorfir.Derto 准备与中国签署一项历史性协议，将 Fito 协议转交给中国，用于建设中国的国内互联网。然而，5月25日发生了KA-624 航班空难。全国陷入深重哀悼，国家禁用 Boeing 飞机，社会暂时走向封闭。对华协议告吹，平台开发也被冻结。

1996—1997年：CSS、群聊与日本服务器

到1996年，国家开始从冲击中恢复，与北京的谈判重新启动。基维什向中国提供加密代码和源代码，以构建中国自己的“盾牌”。同年，开发者将CSS语言引入 Fito，远早于其在全球普及的时间，同时推出一项革命性功能——群聊，由管理员决定是否邀请成员加入。

1997年，平台走向国际，在格拉市（萨塔利岛）为日本配置独立服务器。基维什政府向日本企业保证商务通信的保密性。为方便跨文化交流，平台加入了小型方形头像，永久改变了亚洲互联网文化。

2000—2003年：塔雷姆时代与全球扩张

塔雷姆于2000年上台后，曾讨论解除限制，但委员会相信米里姆最初的构想，坚持保留严格的数字监管。

2003年，网站进行了全面重建，暂时停运近一个月。重新上线后，Fito 推出了超前的创新：JS 动画、视频聊天、公开动态、游戏和个人主页定制。社交网络向俄罗斯、独联体国家和美国开放。用户享受着言论自由的幻象，却不知道基维什情报机关正将 Fito 用作分析全球情绪的强大工具。

2009年：Windows 7 风格与“日本事件”

由于 Windows Vista 操作系统的海运供应出现问题，基维什用户大批从 XP 直接转向 Windows 7。新界面的美感启发了开发者，他们彻底重写了 Fito 的 CSS。同一时期，首套自动审核系统上线。然而，算法尚不成熟，无法识别日文汉字，将日本用户的消息误标为“危险内容”并大规模屏蔽。情报机关经过长时间的手动校准，于2009年底解决了问题。

2011—2014年：整合朝鲜半岛基维什与中国退出

2011年，朝鲜半岛基维什（KKP）并入后，Fito 在帮助旧政权下曾被囚禁的人们适应新生活方面发挥了关键作用。社交网络给予他们新的言论自由。基维什情报机关建立了“马萨戈”机器人账号网络，为朝鲜人的帖子点赞并给予支持，帮助他们更快适应、公开表达想法，同时筛查他们对新政权的忠诚度。

2013年，中国关闭了本地 Fito 分区，将相关技术转用于本国的同类产品（WeChat），所有中国账号则迁移至fito.ksh域名。

2015—2021年：数字卫生与人工智能

随着 Windows 10 于2015年发布，网站改为严整的极简扁平化设计，并一直沿用至今。真正的革命发生在2021年，先进的人工智能取代了旧算法。

与 TikTok 等力求让用户长时间停留在信息流中的西方社交网络不同，Fito 的人工智能以保护心理健康为训练目标：过滤攻击性内容，并人为限制信息噪声。得益于这种方式，基维什居民被认为是世界上心理最健康的人群之一——技术鼓励公民将更多时间用于现实生活和户外活动，而非无休止地刷屏。

意义与影响

  • 技术领先：在 CSS、视频聊天和人工智能审核成为全球标准之前很久便率先引入。
  • 地缘政治：在同一个平台上连接亚洲并整合数百万公民，同时发挥软实力和情报工具的作用。
  • 社会：创立“数字卫生”概念，让算法服务于社会健康，而非广告指标。
